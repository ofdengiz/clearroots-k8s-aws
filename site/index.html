Operational profile

Designed to stay clear under support pressure

This package remains intentionally small: a static site, a container image, a Kubernetes deployment, a NodePort service, a Caddy edge, and a Route 53 record. That keeps troubleshooting direct. If the domain resolves, the worker answers on 443, and the pods are healthy, the service is healthy.

The mission-facing presentation can evolve without changing the infrastructure model. Updating the hero image or page copy does not require redesigning the public path, which keeps content work and platform work cleanly separated.

Delivery summary

Low-cost architecture with a more credible front door

  • Terraform provisions the EC2 nodes, IAM profile, Elastic IP, security group, and Route 53 record.
  • The worker is the only public node, which keeps the entry surface narrow and predictable.
  • Docker packages the site separately from the infrastructure so presentation updates do not require redesigning the platform.
  • The bundled hero image now gives the public site a stronger first impression while still shipping as a simple static payload.
